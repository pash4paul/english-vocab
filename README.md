# English — тренажёр английских слов

Интервальные повторения английской лексики. Слова берутся из списка
**Oxford 3000/5000 по уровням CEFR**: сначала весь A1, потом A2 и дальше.
Работает в браузере и на телефоне, офлайн, без сервера и без регистрации.

```bash
npm install
npm run dev       # http://localhost:5173
```

## Что внутри

```
data/oxford-5000.tsv        план: 4948 слов с уровнями A1–C1
data/*.yaml                 словарь: перевод, тема, часть речи — источник правды
data/irregular-verbs.tsv    неправильные глаголы
   ↓  npm run deck
src/generated/deck.json     собранная колода (в git не хранится)
   ↓  vite
приложение (React + PWA)    прогресс в IndexedDB, только в этом браузере
```

Сейчас в словаре **2389 слов**: уровни A1, A2 и B1 разобраны целиком
(897 + 792 + 690 из плана) плюс горсть слов, которые понадобились по смыслу.
B2 и C1 — 2568 слов — лежат в плане и ждут своей очереди; `npm run coverage`
покажет, сколько осталось.

## Шесть упражнений на одно слово

Карточки открываются по очереди: следующая появляется, когда предыдущая
закрепилась. Так одно слово растёт от узнавания до активного владения.

| Ступень | Вопрос | Ответ |
|---|---|---|
| `recognize` | `water` | выбрать перевод из четырёх |
| `listen` | 🔊 | выбрать перевод из четырёх |
| `spell` | 🔊 | набрать слово буквами |
| `produce` | «вода» | набрать слово |
| `cloze` | `Can I have a glass of _____?` | набрать форму из предложения |
| `forms` | `child → множественное число` | `children` |

Диктант (`spell`) стоит третьим намеренно: в английском написание и звучание
живут порознь, и «слышу, но не напишу» — самая частая дырка.

Расписание считает FSRS. Каждая ступень живёт своим графиком: узнавание может
уйти на месяц, пока диктант того же слова возвращается через день.

## «Уже знаю это слово»

Если язык уже в работе, половина словаря знакома, и прогонять её лестницей —
пустая трата времени. Отметить известное можно двумя способами:

- **на карточке знакомства** — кнопка «Уже знаю это слово»: слово уходит сразу,
  вместе со своей первой карточкой;
- **в словаре** — кнопка «Уже знаю» у раскрытого слова, а кнопка
  «Уже знаю все · N» в шапке применяется ко всему, что сейчас отфильтровано.
  Отобрал уровень A1 — отметил весь уровень одним нажатием.

Отмеченные слова не попадают ни в новые, ни в повторения. Фильтр «Уже знаю»
показывает их списком, «Вернуть в учёбу» возвращает — вместе с прогрессом,
который у слова уже был.

## Проверка ответа

Обязательны буквы. Необязательное ошибкой не считается, но и точным ответом
тоже: показывается правильный вариант, а карточка идёт как «трудно».

| Ввод | Эталон | Вердикт |
|---|---|---|
| `water` | `water` | точно |
| `Water.` | `water` | точно — регистр и точка не считаются |
| `to go` | `go` | верно, но пишется иначе |
| `colour` | `color` | верно, но пишется иначе (британское) |
| `ice-cream` | `ice cream` | верно, но пишется иначе |
| `hous` | `house` | ошибка |
| `cats` | `cat` | ошибка — это другая форма |

Список британских написаний закрытый и лежит в `src/lib/english.mjs`. Правила
на суффиксы (`-ise → -ize`, `-our → -or`) заманчивы, но ломаются на `promise`,
`hour`, `four` — поэтому пары перечислены поштучно.

Строгий режим (Настройки → Проверка ответа) делает ошибкой и это.

## Формат словаря

Один файл — одна тема. Обязательны только `en` и `ru`:

```yaml
topic: Город
words:
  - en: bridge
    ru: мост
    pos: noun
    example: The bridge is closed today.
    exampleRu: Мост сегодня закрыт.
```

Остальное — по необходимости:

| Поле | Когда нужно |
|---|---|
| `level` | только если слова нет в списке Oxford (слово из урока) |
| `uncountable: true` | неисчисляемые: money, advice, news — множественного нет |
| `gradable: false` | прилагательные без степеней: main, married, online |
| `forms` | когда правило отказалось или слово исключение |
| `irregular: true` | формы вписаны руками и расходиться с правилом им можно |
| `note` | чем слово необычно; видно на обороте карточки |
| `forms: { plural: ~ }` | формы не бывает вовсе — не выводить и не спрашивать |

Уровень CEFR подставляется автоматически из плана Oxford. Часть речи:
`noun verb adj adv phrase prep pron num conj det exclam modal article other`.

Глаголы пишутся без «to»: `en: buy`. Служебное «to» — не часть слова.

## Формы: что выводится само

Сборка выводит формы по правилам и ничего не спрашивает у человека там, где
правило надёжно:

```
noun  → plural                       cat → cats, city → cities, box → boxes
verb  → third, ing, past, participle work → works, working, worked, worked
adj   → comparative, superlative     big → bigger, biggest; happy → happier
```

Неправильные глаголы берутся из `data/irregular-verbs.tsv` — 160 глаголов,
закрытый список фактов языка. Несколько допустимых форм пишутся через `|`:
`learned|learnt` показывает первую, а вторую тоже принимает в ответе.

Где правило ненадёжно, оно **отказывается** и говорит почему:

- множественное на `-f`/`-fe`: `leaf → leaves`, но `roof → roofs`;
- множественное на согласную + `-o`: `potato → potatoes`, но `photo → photos`;
- степени сравнения длинных прилагательных: `more beautiful` — это конструкция,
  а не форма слова, и спрашивать её нечему не учит.

Пустая клетка честнее выдуманной формы: упражнение просто не спросит её.
Сборка перечисляет такие места, заполняются они ключом `forms:`.

## План изучения

`data/oxford-5000.tsv` собирается из PDF Oxford скриптом:

```bash
npm run import:oxford            # ждёт PDF в ../dictionaries
npm run import:oxford -- ~/путь  # или укажи папку
```

Разбор PDF свой, без зависимостей: потоки внутри файла сжаты deflate, текст
в них лежит обычными операторами. Из 5315 записей не разбираются два слова
(`seldom`, `selective`): у них метка части речи набрана шрифтом с собственной
кодировкой. Ещё несколько слов кернинг разрывает пополам («s cope»), их скрипт
склеивает обратно и печатает список склеенного — молчаливых потерь нет.

Сколько уже разобрано:

```bash
npm run coverage        # сводка по уровням + следующие слова
npm run coverage -- A2  # конкретный уровень
```

## Нагрузка

```bash
npm run simulate        # 60 учебных дней при 8 новых словах в день
```

На 60-й день это ~115 карточек в сутки и 480 затронутых слов. Если много —
уменьшите «Новых слов в день» или поставьте потолок повторений: отложенные
повторения не пропадают, а переносятся на следующий день.

## Прогресс и перенос между устройствами

Прогресс лежит в IndexedDB того браузера, где вы занимались. На сервер ничего
не уходит, поэтому и синхронизации нет.

Настройки → Данные:

- **Скопировать / Вставить** — через общий буфер Apple это одно нажатие
  на каждой стороне; самый простой путь между Mac и iPhone;
- **Файл / Из файла** — настоящий бэкап, кладите его куда-нибудь ещё;
- **Сбросить** — необратимо.

В файле кроме машинной части лежит человекочитаемая сводка: список слов,
состояние карточек, счёт ответов. Её видно глазами, и по ней сразу понятно,
что бэкап не пустой.

## Озвучка

Нужен системный английский голос. macOS: Системные настройки → Универсальный
доступ → Устная речь → Системный голос → Управление голосами → English.
Предпочитается американский голос: словарь американский.

В Safari озвучка работает, в Chrome обычно молчит — баг браузера, обойти
не удалось. Диагностика с полным следом вызова: Настройки → Озвучка →
«Проверить озвучку».

## Публикация

Статический сайт на GitHub Pages, каждый пуш в `main` пересобирает его сам
(`.github/workflows/deploy.yml`). Один раз в настройках репозитория:
Settings → Pages → Source → GitHub Actions.

В CI перед сборкой прогоняется `npm run check`, поэтому сломанный словарь
до сайта не доезжает.

На телефоне сайт ставится на домашний экран (Safari → «Поделиться» →
«На экран "Домой"») и после этого работает офлайн.

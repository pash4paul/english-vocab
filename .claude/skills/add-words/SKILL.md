# Добавление слов в словарь

## 1. Возьми следующую порцию из плана

План изучения уже лежит в репозитории — это `data/oxford-5000.tsv`, список
Oxford 3000/5000 с уровнями CEFR. Что из него уже разобрано, показывает:

```bash
npm run coverage            # сводка по уровням + следующие слова
npm run coverage -- A2 60   # конкретный уровень, сколько слов показать
```

Порция за раз — 40–80 слов. Больше не надо: качество перевода падает раньше,
чем кончается терпение.

Если дали скриншоты урока — прочитай **все** файлы по одному инструментом Read.
Не выборочно: пропущенный файл заметят не сразу, а слова будут потеряны.

## 2. Разложи по темам

Один файл в `data/` — одна тема. Загляни в существующие файлы: подходящая тема
может уже быть, тогда дописывай в неё, а не создавай близкую по смыслу.

Списки слов приходят по алфавиту или по частям речи. **Это не темы.**
Раскладывай по смыслу — «Еда и напитки», «Работа и деньги», — иначе в приложении
фильтр по темам бесполезен, а отвлекающие варианты в упражнениях подбираются
хуже: различать «стол» и «стул» полезнее, чем «стол» и «понимать».

Имя файла — с числовым префиксом по порядку: `20-city.yaml`.

## 3. Пиши минимально

Обязательны только `en` и `ru`. Формы **не заполняй** — множественное число,
`-s`, `-ing`, прошедшее и степени сравнения выводятся при сборке, а неправильные
глаголы берутся из `data/irregular-verbs.tsv`. Уровень тоже не указывай: он
подставится из списка Oxford.

```yaml
topic: Город
words:
  - en: bridge
    ru: мост
    pos: noun            # noun verb adj adv phrase prep pron num conj det exclam modal article other
    example: The bridge is closed today.
    exampleRu: Мост сегодня закрыт.
```

Что писать руками:

- `uncountable: true` — у неисчисляемых существительных (money, advice, news).
  Иначе появится вопрос про несуществующее множественное число.
- `gradable: false` — у прилагательных без степеней сравнения (main, married,
  online). Иначе правило выведет «mainer».
- `forms:` и `irregular: true` — только там, где сборка сама попросит.
- `level:` — только для слов, которых нет в списке Oxford (слова из урока).

Глаголы — без «to»: `en: buy`, а не `to buy`. Служебное «to» в ответе
принимается и с ним, и без него.

Примеры добавляй там, где они естественны, и обязательно с `exampleRu`.
Пример включает упражнение с пропуском — но лучше десять хороших примеров,
чем сто натянутых.

## 4. Проверь

```bash
npm run check
```

Разбирай вывод целиком, не только ошибки:

- **«Nested mappings are not allowed»** — в значении есть двоеточие.
  Оберни всё значение в кавычки.
- **«YAML прочитал слово как логическое значение»** — слова `true`, `false`,
  `yes`, `no`, `on`, `off`, `null` надо писать в кавычках: `en: 'no'`.
- **«дубль слова из …»** — слово уже есть. Не добавляй второй раз; если у него
  другое значение, допиши перевод к существующей записи.
- **«тот же перевод у …»** — разведи уточнением в скобках. Это не мелочь:
  на карточке RU→EN видно «быстрый», а какое из двух слов вводить — непонятно.
- **«расхождение с правилами»** — форма, которую ты вписал руками, не совпала
  с правилом или с таблицей неправильных. Либо опечатка, либо настоящее
  исключение: тогда `irregular: true` и короткий `note`, чем оно необычно.
  **Правило под слово не подгоняй.**
- **«нет формы plural»** — правило отказалось (слова на `-f`, `-fe`, согласная +
  `-o`). Впиши форму руками через `forms:`.
- **«слова нет в списке Oxford»** — либо опечатка в написании, либо слово
  действительно из урока. Во втором случае добавь `level:`.

## 5. Проверь качество глазами

Валидатор ловит совпадения, но не неточный перевод. Пройди по своей порции
и спроси себя:

- перевод отвечает на вопрос «что это значит», а не «как это примерно»?
- у многозначного слова выбран тот смысл, который имелся в виду в списке
  (там смысл иногда подсказан в колонке hint: `bank (money)`);
- уточнение в скобках стоит там, где без него слово не отличить от соседа.

## 6. Отчитайся

Коротко и цифрами: сколько слов добавлено, разбивка по темам и частям речи,
сколько исключений помечено, какие дубликаты нашлись и что с ними сделано,
сколько осталось до конца уровня (`npm run coverage`).

Пустая клетка — не всегда недоработка. Если множественного числа у слова
не бывает, так и скажи, не выдумывай форму.
